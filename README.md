## Como executar
Abra `index.html` no navegador. Não há dependências nem instalação.

## Estrutura
`index.html`, `curriculo.html`, `formulario.html`, `multimidia.html`, `graficos.html`, `css/estilos.css`, `js/scripts.js`, `img/`, `midia/`


## Bootstrap (CP4)
Bootstrap 5.3.3 via CDN, com CSS personalizado carregado depois. Classes utilizadas: `text-center` (rodapé), `d-flex` e `flex-wrap` (links do currículo), `img-fluid` (logo da página inicial).
